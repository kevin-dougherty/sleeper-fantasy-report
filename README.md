# Sleeper Weekly Fantasy Football Report

A Python script that pulls data from the free, public [Sleeper API](https://docs.sleeper.app/), builds a weekly recap for a fantasy football league, adds a short AI-generated blurb via the Claude API, and posts the whole thing to a GroupMe group — automatically, every Tuesday, via GitHub Actions.

Built for leagues that pay out weekly prizes for the top-scoring team and the top-scoring player at each position.

## What it does

Given a league ID and week number (or by auto-detecting the current NFL week), the script pulls that week's matchups and rosters and produces a report with:

- **Team of the Week** — the highest-scoring team (weekly high-score payout)
- **Position point leaders** — the top scorer among starters at QB, RB, WR, and TE (position payouts)
- **Highlights** — closest matchup, biggest blowout, and the highest-scoring player left on a bench ("bench regret")
- **A short AI-generated recap** (optional) — 2-3 fun, lightly trash-talking sentences generated by Claude, layered on top of the stats

The report prints to the console, saves to `weekly_report.txt`, and (if configured) posts to a GroupMe group via a bot.

## Setup

```bash
git clone https://github.com/<your-username>/sleeper-fantasy-report.git
cd sleeper-fantasy-report
pip install -r requirements.txt
```

### Config

Real league/API values are kept out of the repo. Copy the template and fill in your own:

```bash
cp config.example.json config.json
```

```json
{
  "league_id": "your Sleeper league ID",
  "week": null,
  "groupme_bot_id": "your GroupMe bot ID",
  "anthropic_api_key": "your Anthropic API key"
}
```

`config.json` is gitignored, so it stays local to your machine and never gets pushed. Leave `week` as `null` to auto-detect the current NFL week, and leave `groupme_bot_id` / `anthropic_api_key` blank if you don't want posting or AI commentary.

**Finding your league ID:** open your league in the Sleeper app or on sleeper.com — it's the numeric string in the URL (`sleeper.com/leagues/<league_id>/...`).

**Getting a GroupMe bot ID:** go to [dev.groupme.com/bots](https://dev.groupme.com/bots), create a bot for your group, and copy its Bot ID.

**Getting an Anthropic API key:** create one at [console.anthropic.com](https://console.anthropic.com) (this step is optional — the report works fine without AI commentary).

## Usage

```bash
python src/sleeper_weekly_report.py
```

Options:

```bash
python src/sleeper_weekly_report.py --league-id 378845311639904256 --week 3
python src/sleeper_weekly_report.py --no-post     # print/save the report but skip GroupMe
```

Config is resolved in this order (highest priority first): CLI args → environment variables → `config.json`.

## Automating it with GitHub Actions

`.github/workflows/weekly-report.yml` runs the script every Tuesday at 12:00 UTC and posts straight to GroupMe. Since `config.json` isn't committed, the workflow reads the same values from **GitHub Secrets** instead:

1. In your repo: **Settings → Secrets and variables → Actions → New repository secret**
2. Add:
   - `LEAGUE_ID`
   - `GROUPME_BOT_ID`
   - `ANTHROPIC_API_KEY` (optional — omit to skip AI commentary)
3. That's it — the workflow will run automatically every Tuesday, or you can trigger it manually from the **Actions** tab (`Run workflow`).

Adjust the cron schedule in the workflow file if you want a different day/time — GitHub Actions cron is always in UTC.

## Notes

- Position leaders are calculated from **starters only**.
- The `players/nfl` endpoint returns Sleeper's full player dictionary (a few MB); fine to refetch on a weekly cron, but worth caching locally if you run this more often.
- GitHub Actions cron jobs can run a few minutes late during high-traffic periods (like Tuesday mornings across all of GitHub) — that's normal.
